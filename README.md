## 📌 About the Project

**TextLens** is a browser-based Text Complexity Analyzer developed as part of a **Text & Speech Analysis** project.

The application analyzes written text and estimates its linguistic complexity by examining vocabulary, word length, sentence structure, sentence length, and other text characteristics.

It provides a simple **Complexity Score**, reading profile, detailed statistics, estimated reading time, and readability insights.

The entire application works directly in the browser using JavaScript.

---

## 🎯 Objective

The main objective of TextLens is to help users understand the complexity and readability of a piece of text.

It can be useful for:

- 📚 Students

## ✨ Key Features

### 🔢 Complexity Score

Generates a **0–100 complexity score** based on the linguistic characteristics of the entered text.

### 📖 Complexity Classification

The text is classified into:

- 🟢 Easy
- 🟡 Moderate
- 🟠 Advanced
- 🔴 Highly Complex

### 📝 Text Statistics

The application calculates:

- Total word count
- Sentence count
- Average word length
- Average sentence length
- Unique word count
- Vocabulary ratio
- Longest sentence

### 📊 Reading Profile

TextLens analyzes:

- Vocabulary complexity
- Sentence structure
- Overall difficulty

### ⏱️ Reading Time

Estimates the approximate time required to read the entered text.

### 💡 TextLens Insight

Provides a short explanation based on the calculated complexity level and gives readability suggestions.

### 📱 Responsive Design

The interface works across:

- Desktop
- Tablet
- Mobile devices
